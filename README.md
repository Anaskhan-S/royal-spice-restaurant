# Royal Spice Restaurant Website

A responsive restaurant website built using HTML, CSS and JavaScript.

## Project Overview

Royal Spice is a fictional restaurant website
created as a frontend development portfolio project.

## Features

- Responsive website layout
- Navigation menu
- Restaurant introduction
- Food menu section
- Contact section
- WhatsApp enquiry button

- CSS3
- JavaScript
